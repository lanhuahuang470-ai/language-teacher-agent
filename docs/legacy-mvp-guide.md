## 1. 项目概述与 MVP 边界

### 1.1 一句话定义

一个面向中文母语成人学习者的英语教学助手，通过 Web 文字交互完成个性化教学、练习和复习。

### 1.2 用户范围与分级目标


| 等级段 | 典型目标 | 教学重点 |
|---|---|---|
| A1–A2 | 生存英语与日常交流 | 高频词汇、基础句型、短文理解与简单表达 |
| B1–B2 | 独立表达、职场与旅行沟通 | 连贯叙述、观点表达、复杂文本与场景任务 |
| C1–C2 | 学术、专业与高阶精准表达 | 语域、修辞、隐含意义、综合论证与风格控制 |

> **范围原则**：架构、数据模型和 Agent Schema 按 A1–C2 设计；首个可交付版本优先提供 A1–B1 的可验收教学内容，B2–C2 按后续阶段扩展。
